# shoot-schedule-template

A Claude Code skill + generator that builds a shoot calendar for the sports
teams you photograph — any team, any league. Nothing about a specific team
or league is hardcoded: an onboarding flow asks what you shoot, finds each
team's schedule itself (fresh web search, no built-in league table), and
confirms it with you before writing anything.

## Quick start

```bash
git clone <this-repo-url>
cd shoot-schedule-template
./setup.sh
```

Then, in Claude Code, ask it to **"set up my shoot calendar"**. It will:

1. Ask what teams you shoot, home games only or home + away, and whether
   you want a pre-game arrival reminder event.
2. Search for each team's official schedule source and show you a sample
   before committing to a full fetch.
3. Generate `public/shoots.ics` locally.
4. Ask how you want it delivered — see below.

Running it again later lets you add another team or refresh an existing
one's schedule (new games since last run).

## Delivery methods

- **Import into iCloud Calendar** (macOS only) — opens the generated `.ics`
  in Calendar.app; you pick an iCloud calendar to import into, so it syncs
  across your devices. No hosting account needed. On a refresh, pick the
  *same* calendar again — stable event UIDs mean it updates in place rather
  than duplicating.
- **Deploy via Vercel** — produces a hosted subscribe URL any calendar app
  (Apple Calendar, Google Calendar, Outlook) can poll automatically.
  Requires a Vercel account (`vercel login`). Cross-platform, since it's a
  URL rather than a local import.

**Known limitation**: the iCloud-import path is macOS/iCloud-specific. If
you're not on macOS/iCloud, use the Vercel path.

## How it works

- `preferences.json` — your config: which teams, home/away setting, arrival
  reminder toggle + lead time, event duration, title prefix, and the
  confirmed schedule source per team.
- `teams/{slug}.json` — fetched schedule data per team (venue + games).
  Regenerated by re-running the onboarding flow, not hand-edited.
- `scripts/generate-ics.mjs` — reads both, writes `public/shoots.ics`.
  Run directly with `npm run generate` any time you want to rebuild locally
  without going through the skill.

## Layout

- `SKILL.md` — instructions Claude follows when invoked.
- `setup.sh` — symlinks this repo into `~/.claude/skills/shoot-schedule-template`.
- `scripts/generate-ics.mjs` — the generator.
- `vercel.json` — build/output config for the Vercel delivery path.
- `teams/` — starts empty; populated by the onboarding flow.
